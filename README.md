📊 Customer Churn Analysis
📌 Project Overview
An end-to-end Customer Churn Analysis project using Python, Pandas, Excel, and Power BI to identify customer churn patterns and generate actionable business insights.
🎯 Objectives
Clean and preprocess customer data.
Perform exploratory data analysis.
Analyze churn across customer segments.
Identify factors associated with customer churn.
Build an interactive Power BI dashboard.
🧹 Data Cleaning
Data was cleaned and prepared using Python and Pandas, including:
Handling missing values
Removing duplicates
Cleaning text data
Standardizing data types
Creating tenure groups
Preparing data for analysis
📊 Power BI Dashboard
The dashboard provides KPIs and visual analysis of:
Total Customers
Churn Rate
Churned & Retained Customers
Total Revenue
Average Monthly Charges
Average Tenure
Churn by Contract, Subscription, Internet Service, Payment Method, and State

💡 Key Insights
The analysis helps identify customer segments with higher churn and understand how contract type, subscription, payment method, internet service, monthly charges, and tenure are related to customer retention.
